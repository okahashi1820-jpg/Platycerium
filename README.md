# ビカクの美学

ビカクシダ（リドレイ、ウィリンキー）を1週間ずつ育て、品評会の頂点「天下会」でSランクを目指す育成ゲーム（スマホ向け・オフライン対応のWebアプリ）。

- 公開URL: https://okahashi1820-jpg.github.io/Platycerium/
- Chromeで開き、メニューの「ホーム画面に追加」（または設定画面の「アプリとして追加」）でアプリとして使えます。
- セーブはその端末のブラウザ内にだけ保存されます。別の端末へ移すときは、設定画面のセーブコードを使います。
- プログラムとグラフィックはAI（Claude）の支援で作成しています。
